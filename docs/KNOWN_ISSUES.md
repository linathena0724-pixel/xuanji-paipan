# 已知问题（v0.2.0，配置 2026-09-30.v1.5）

所有口径都在 `src/config.js`，下面这些问题定下来以后只改配置，不动代码。

1. **神煞图谱维度分**：权重按 6 张样本盘标定，大部分维度误差在 ±5 分以内。同一颗神煞在多柱命中时，参考软件的分数有时会更高，但样本里也有反例，规则还定不下来，等样本多了再定。
2. **类型标签**：强度分的分界线（尤其均衡型和身强型之间只差 5 分）是用 5 张样本盘定的，样本多了要复校。分界线在 `src/config.js`。
3. **五行占比**：土行在部分盘上系统性偏高（+2.5～+8 个百分点），疑为合局、旺衰一类的非线性修正，要攒到 8～10 张样本盘再定下一版。
4. **神煞查法的流派差异**：月德合、金舆、亡神等个别神煞，在个别盘上与部分排盘软件判定不同，本服务照引擎和古法收录。差异会直接反映在图谱分数和稀有前三上。
5. **两套时间口径排出不同的盘**：出生时间靠近时辰交界、或在 23 点到 24 点之间的，真太阳时和北京时间排出来的日柱或时柱可能不同。服务会在 `warnings` 里提示，并在 `timeCheck` 里给出两种结果。换日规则固定为 23 点换日（子初换日），不支持早晚子时派。
6. **海外出生**：城市只支持引擎自带的中国省市区，海外出生暂不支持（会返回 `LOCATION_NOT_FOUND`）。
7. **紫微斗数**：规格里有，这一版没做。
